# Screenshot Capture Checklist

No images or media are included in this repository by design. Before submitting, capture your own screenshots of:

- Before design / wireframe
- Final desktop layout
- Tablet layout
- Mobile layout
- Navigation bar
- Hero section
- Features section
- Pricing cards
- Testimonials
- Footer
- VS Code project structure
- Blade Components folder
- Public GitHub repository

Save captures in this folder using clear names such as `desktop-home.png`, `mobile-reserve.png`, and `before-wireframe.png`.
